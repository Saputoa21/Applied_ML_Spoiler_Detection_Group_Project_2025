**Spoiler Detection Project**

This repository contains the group project for the **Applied Machine Learning for Language Processing** course. 
Our team tackled the challenge of binary classification to identify "spoilers" in text, comparing Deep Learning models (BERT Base Uncased, DistilBERT, RoBERTa, ELECTRA) 
with traditional feature-based (Random Forest, Decision Tree) and statistical (Naive Bayes) approaches.
